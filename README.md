# love-in-rhythm
🎵 About the Game
Love In Rhythm Preview is an experimental rhythm game prototype created to test the basic gameplay concept, music timing, and player interaction.
This is an early preview version, so features, visuals, sounds, and mechanics may change in future updates.

✨ Features
♡ Early rhythm gameplay concept 
♡ Simple prototype build 
♡ Experimental mechanics 
♡ Free preview version 

🎮 How to Play
Download the ZIP file, extract it, and run the game executable inside the folder.
Use the keyboard to play along with the rhythm. Press the correct keys at the right timing to score points.

⚠️ Please Note
This is a work-in-progress project. Bugs, missing features, or unfinished content may appear.

💌 Thank You

Install instructions
How to Play
1. Download the game file.
2. Extract the ZIP file to any folder on your computer.
3. Open the extracted folder.
4. Run the game executable file.
5. Follow the on-screen instructions and enjoy the preview.

Controls
- Use the keyboard to interact with the game.
- Press the correct keys in rhythm with the music.
- Try to keep your timing accurate to get a better score.
Notes
This is an experimental prototype, so some features may be unfinished or changed in future versions. If you find any bugs or have feedback, feel free to leave a comment.

6. Uninstalling the Game
This game does not require a traditional installation. To remove it from your computer, please restart your system to ensure that any remaining background processes are fully closed. After restarting, simply delete the game folder from your computer.
